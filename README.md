# ImunoScan: Ciência em Movimento

Leia integralmente todos os arquivos anexados antes de iniciar.

Quero fazer uma prova de conceito completa do novo site da ImunoScan.

Para este teste, ignore a divisão em lotes do Prompt Master 02 e implemente o site completo em uma única execução, seguindo todas as demais regras do Prompt Master.

O conteudo-produtos-imunoscan-v2-validado.json é a fonte de verdade para o conteúdo.

O DESIGN-IMUNOSCAN.md é a autoridade para identidade visual, layout e motion design.

Quero uma experiência moderna, científica, elegante e claramente identificável como ImunoScan.

Dê atenção especial ao conceito “Ciência em movimento” e ao uso das hemácias/glóbulos vermelhos como elemento visual proprietário da marca.

Implemente as animações previstas no DESIGN: hemácias flutuantes no hero, profundidade, movimento ambiental, parallax discreto quando apropriado, scroll reveals e microinterações. Preserve performance, responsividade, prefers-reduced-motion e acessibilidade.

Não faça apenas uma landing page. Implemente a arquitetura completa disponível nos arquivos: Home, Produtos, Diagnóstico & Imuno-hematologia, páginas de categorias, páginas de produtos alimentadas pelo JSON, Life Sciences, Aplicações, Documentação Técnica, A ImunoScan, Cotação e Contato.

Não invente produtos, marcas, registros, especificações, números ou conteúdo técnico que não esteja nas fontes.

Não copie visualmente o site antigo. Use a identidade histórica apenas como origem da marca e desenvolva a nova linguagem definida no DESIGN-IMUNOSCAN.md.

Antes de considerar o trabalho concluído, revise desktop e mobile e faça uma passada final de refinamento visual, consistência, motion e performance.
